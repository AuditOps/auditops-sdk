# Vision
Gather evidence, perform testing, and summarize results in ~5 lines of code per tool.

## What this library does:
1. Evidence Collection: Gathers evidence (JSON files) directly from your vendor's API or SDK.
2. Testing: Conduct logic based configuration tests (encryption, MFA, key rotation, etc).
3. Report Building: Builds JSON & PDF reports summarizing findings from each test & tool.
4. Upload: Share full audit packages (evidence & audit reports) with auditors, customers, and regulators.

## Use Cases:
- Audits: Provide your auditor high-quality evidence ~5 lines of code per tool.
- Vendor Due Diligence: Instead of sending a questionnaire, ask for the AuditOps report.

## Design Philosophy:
1. Lightweight: This library doesn't connect or integrate with your tools.
