# Environment Setup Instructions

Follow the instructions below to install the required tools (Python, Pip, AWS CLI, and AuditOps). These instructions are required across the various providers (AWS, GitHub, etc).

## Install Python

If Python is not already installed, follow the steps in the tutorial below:

- [Python Installation Tutorial](https://www.youtube.com/watch?v=D2cwvpJSBX4)

Verify the installation:

```bash
python --version
```

---

## Install Pip

Install pip for your operating system.

- [Mac Installation Tutorial](https://www.youtube.com/watch?v=xAhqhPk1ij0)
- [Windows Installation Tutorial](https://www.youtube.com/watch?v=MZZwXonQwdI)

Verify the installation:

```bash
pip --version
```

---

## Install the AWS CLI

Install the AWS CLI for your operating system.

- [Mac Installation Tutorial](https://www.youtube.com/watch?v=U0AmeqL4DfE)
- [Windows Installation Tutorial](https://www.youtube.com/watch?v=jCHOsMPbcV0)

Verify the installation:

```bash
aws --version
```

---

## Install AuditOps

Install the latest AuditOps package from PyPI.

```bash
pip install -U auditops
```
