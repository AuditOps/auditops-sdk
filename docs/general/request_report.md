# How to Request an AuditOps-SDK Report

Send your vendor an email similar to the one below. Sit back, grab a coffee, and wait for them to share the report.

> 💡 **Note for Auditors:** Vendor due diligence is the primary use case of this project. Auditors should modify the language below, ensure the report isn’t using `summary_mode`, and request the supporting evidence as a ZIP file.

### Email Template 

**To:** `Vendor Sales Team Contact`  
**From:** `TPRM Contact`  
**CC (Optional):** info@auditops.io  
**Subject:** Vendor Due Diligence (AuditOps report)


```text
Hey [Vendor Contact Name],

I hope you’re doing well! We are interested in moving forward with Acme Co. As part of our due diligence process, we would like to review your most recent AuditOps report.

AuditOps is an open-source Python library that generates an anonymized scan of your AWS environment. This allows us to verify that your team follows AWS best practices (MFA, access key rotation, etc).

Below are some resources to explain more about AuditOps, and help you generate the report:
- AuditOps GitHub Project: https://github.com/AuditOps/auditops-sdk
- AuditOps FAQs: https://github.com/AuditOps/auditops-sdk/blob/main/docs/general/faqs.md
- AWS Setup Instructions: https://github.com/AuditOps/auditops-sdk/blob/main/docs/providers/aws/getting-started.md

I've CC'ed the AuditOps support team if you have any questions! You can use their upload.auditops.io API / portal, or feel free to just email us a copy of the PDF report.

We really appreciate your help here. Please let us know if you need anything from us.

Best,
[Your Name]
```
